Firmware area check for the §5 selection, run 2026-10-30.

Why this file exists: live/auto/config sets --archive-areas main. That is a
deviation from Debian's own live images, which ship non-free-firmware, and
M0's build log shows the consequence. §11 wants the numbers, not the reasoning.

Method: the trixie main index already on the host (/var/lib/apt/lists, from
the main-only 0000debian.sources) plus the non-free-firmware index fetched
read-only over HTTPS from the archive. Nothing on the host was reconfigured.
