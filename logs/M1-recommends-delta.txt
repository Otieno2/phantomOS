Recommends delta for the §5 selection, measured 2026-10-30.

Why this file exists: live/auto/config sets --apt-recommends false. That is the
one behaviour change in the build configuration, and §11 does not allow a decision
like that to rest on taste. These are the numbers behind it.

Method: apt-get --simulate against the build host's trixie 13.7 package indices
(/var/lib/apt/lists, refreshed 2026-10-29 per logs/M0-toolchain.log) with an empty
dpkg status file, so the closure is computed as if from a bare bootstrap:
  apt-get -o Dir::State::status=/root/empty/status --no-install-recommends -s install $SET
  apt-get -o Dir::State::status=/root/empty/status --install-recommends  -s install $SET
